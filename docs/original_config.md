# MiniOneRec 原论文与官方实现

依据 [论文 v1](https://arxiv.org/html/2510.24431) 和 [官方源码固定版本](https://github.com/AkaliKong/MiniOneRec/tree/0cbd94de9ea58c59a6b05d4d1dbda7edf8d5b3b1)。

| 阶段 | 论文 | 官方实现及 Lite 采用口径 |
|---|---|---|
| 数据 | Amazon Industrial，5-core，1996-10 至 2018-11，历史最多 10，全局按目标事件时间切 8:1:1 | README 的起点是通用示例 2017-10，仓库 shell 终点 2018-10。Lite 采用 Python 默认窗口 1996-10 至 2018-11，UTC，过滤边界是 11 月 1 日零时。官方滑窗扩增、排序和分割保留。论文目标规模为 3,685 商品，训练、验证、测试 36,259 / 4,532 / 4,533。实测三组样本数一致，商品目录为 3,686，详见本地验证。 |
| 编码 | Qwen3-Embedding-4B 编码标题与描述 | 保留官方文本拼接和模型池化代码，批大小从 1024 降为 8，最长 2048。 |
| 量化 | RQ-VAE，单卡，20,480 batch，10,000 epochs，学习率 0.001 | 保留三层残差量化、每层 256 码、32 维代码本、MLP、KMeans 初始化和官方训练脚本参数。生成时从最近码开始，对碰撞组仅在最后一级启用 Sinkhorn，最多 20 次，记录仍共享 SID 的商品。README 的 KMeans、FLASH 等属于其他选项。 |
| SFT | Qwen2.5-Instruct，八卡、每卡 128，最多 10 epoch，3e-4 余弦，早停耐心一轮 | 官方运行脚本全局 1024、每卡 16、累积 8。源码按训练步数 5% 验证，耐心 3，默认训练参数使用线性调度。Lite 用 Qwen2.5-0.5B Base、LoRA rank 16、SID 行训练，保留源码的评估频次与耐心，采用论文余弦调度。保留源码的 SID 序列、商品特征及文本与 SID 混合序列目标。论文附录还描述了偏好摘要，选定脚本未启用该数据集。 |
| GRPO | 2 epoch，16 个约束 beam，正确性 + 排序奖励 | 原始实验采用官方 shell 的 beam、beta=0.001、1e-5、温度 1、参考同步；用户要求调整后从 SFT 权重重启的最终实验采用 beta=0.005、学习率 5e-6，其他上述设置保留。关闭动态采样、注入真值和 DAPO。组内优势为 (reward - mean) / (样本标准差 + 1e-4)。策略梯度来自 token log-prob 比值的 detach 形式，加参考模型 KL 后按 completion mask 聚合。 |
| 奖励差异 | 负样本惩罚按候选组内负例重新归一化 | 官方源码用对所有 16 个固定 rank 权重的和归一化，命中项 rank reward 为零，整组未命中时排序奖励也为零。Lite 保留官方实验入口奖励；监督目标从当前样本读取，避免重复历史或验证记录覆盖训练标签。 |
| 评估 | HR/NDCG，单个下一商品真值 | 官方 `evaluate.sh` 设置 beam=50、length penalty=0、最多 256 新 token，候选来自全商品 SID 前缀。保留官方首个命中的 1/log2(rank+1) 折扣，以及按测试样本平均。若碰撞残留，指标按官方 SID 等价口径计算，报告需披露多商品共享同一 SID 的数量。 |

论文 Table 1 的每个单元格为 HR / NDCG，数值为比例。Lite 的保留率分母为 Industrial NDCG@10 = 0.1167。Base、模型尺寸与 LoRA 等配置差异须随比较披露。原论文完整 GPU-hours 待核实。
